### lighthouse museum projects

#### lighthouse lamp changer restoration

- mechanics restoration, cleaning, and lubrication
- electronic control system design and programming
- integration with the museum weather station for change counting —
  it is now more than 9,000 changes!

<div class="pair" markdown="1">

#### weather station

Old Soviet weather station restoration:

- mechanics restoration with original parts preserved and reused
- new electronics design for signal acquisition from the old sensors
- server and local PC programming for data storage and visualisation

<div class="pair" markdown="1">
![Weather station mast with sensors against a blue sky](/img/station1.jpg)
![Weather station mast covered with red ivy](/img/station4.jpg)
</div>

#### light characteristic demo installation

An interactive installation showing different light characteristics. The visitor chooses a real local lighthouse on the touchscreen, reads a caption about it, and watches its light characteristic on a real lens lantern:

- programming
- user interface design
- lens lantern modification for a custom multicolour LED light

</div>
